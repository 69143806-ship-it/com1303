# com1303

#  สัปดาห์ที่ 1 โครงสร้าง HTML และแท็กพื้นฐาน

## ผู้จัดทำ
นายชมะนันท์ พูลศรี  
รายวิชา: COM 1303 การพัฒนาเว็บขั้นพื้นฐาน  

## วัตถุประสงค์ของงาน
เพื่อเรียนรู้โครงสร้าง HTML และการฝึกใช้แท็กพื้นฐานในการสร้างเว็บไซต์

## รายละเอียดผลงาน
สร้างเว็ปไซต์แนะนำตัวเอง โดยใช้ HTML แสดงข้อมูลส่วนตัว ข้อความ รูปภาพ และรายการความสนใจ

## ไฟล์ในโฟลเดอร์
- `index.html` — หน้าเว็บหลัก
- `images/profile.png` — ภาพประกอบหน้าเว็บ
- `README.md` — คำอธิบายงาน

## วิธีเปิดดูผลงาน
1. ดาวโหลดไฟล์จาก GitHub
2. เปิดไฟล์ index.html ด้วยเว็บเบราว์เซอร์
3. ตรวจสอบการแสดงผลของเว็บไซต์

## ผลลัพธ์และสิ่งที่ได้เรียนรู้
เข้าใจโครงสร้าง HTML และสามารถใช้แท็กพื้นฐานสร้างหัวข้อ ย่อหน้า รูปภาพ และรายการได้

## ปัญหาและวิธีแก้ไข
พบปัญหารูปภาพไม่แสดง จึงตรวจสอบและแก้ไข้ไฟล์ให้ถูกต้อง  

## สิ่งที่ต้องการปรับปรุง
ศึกษา CSS เพิ่มเติมเพื่อปรับแต่งเว็บไซต์ให้สวยงามและน่าใช้งานมากขึ้น

## แหล่งอ้างอิง
ระบุที่มาของภาพ เนื้อหา และโค้ดที่ใช้จริง หากสร้างเองให้ระบุว่าเป็นผลงานของตนเอง
