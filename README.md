### กิจกรรมการใช้งาน GitHub
วิชา COM 1303 การพัฒนาเว็บขั้นพื้นฐาน

### 1. Git คืออะไร
Git คือ ระบบควบคุมเวอร์ชันของไฟล์หรือโปรแกรม ใช้บันทึกการเปลี่ยนแปลงของโค้ด สามารถย้อนกลับไปดูหรือเรียกคืนโค้ดเวอร์ชันก่อนหน้าได้

### 2. การทำงานของเว็บไซต์ทำงานอย่างไร
เว็บไซต์ทำงานโดยผู้ใช้เปิดเว็บผ่าน Web Browser จากนั้น Browser จะส่งคำขอ (Request) ไปยัง Web Server เพื่อขอข้อมูล เมื่อ Server ประมวลผลเสร็จจะส่งข้อมูลกลับมา (Response) และ Browser จะแสดงผลเป็นหน้าเว็บไซต์ให้ผู้ใช้เห็น

### 3. เว็บไซต์ต่างจากเว็บแอปพลิเคชันอย่างไร
เว็บไซต์ (Website) เน้นการนำเสนอข้อมูล เช่น เว็บไซต์ข่าวหรือเว็บไซต์แนะนำสถานที่ ส่วนเว็บแอปพลิเคชัน (Web Application) เน้นการให้ผู้ใช้โต้ตอบและทำงานผ่านระบบ เช่น Google Docs หรือระบบซื้อสินค้าออนไลน์

### 4. ให้สร้างคู่มือการใช้งาน GitHub
1. เข้าเว็บไซต์ https://github.com
2. สมัครสมาชิกหรือเข้าสู่ระบบ
3. กดปุ่ม New เพื่อสร้าง Repository
4. ตั้งชื่อ Repository
5. เลือก Public หรือ Private
6. กด Create Repository
7. เพิ่มไฟล์หรือโค้ดที่ต้องการจัดเก็บ
8. กด Commit changes เพื่อบันทึกการเปลี่ยนแปลง
9. คัดลอกลิงก์ Repository เพื่อแชร์ให้ผู้อื่น
